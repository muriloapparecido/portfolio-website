Overview

Anagram is an anonymous group messaging app that lets users communicate freely without revealing their real identities. Each user is assigned a randomized alias per group chat, so members can track conversation threads without ever knowing who's behind each message. Built with a Supabase backend, the app handles authentication, real-time messaging, and group management through a structured relational database while preserving anonymity on the frontend.

What I've Done

  • Set up Supabase authentication with email verification, including a forgot password flow and improved account verification emails.
  • Designed a relational database schema with tables for users, groupchats, group_members, and messages with each message tracked by user ID in the backend for safety and moderation, while remaining anonymous to other users.
  • Implemented Row Level Security (RLS) policies in Supabase to ensure users can only access data they're authorized to see.
  • Built real-time messaging using Supabase's live subscriptions, so messages appear instantly across all group members without refreshing.
  • Developed group chat creation and membership management, allowing users to create chats, add contacts, and dynamically load the correct chats per logged-in user.
  • Resolved user authentication bugs and migrated the backend from Firebase to Supabase for more robust data control.

Technical Stack

  • Backend: Supabase (PostgreSQL, Auth, Realtime)
  • Database: Relational schema with RLS policies for secure, scoped data access
  • Auth: Email sign-in with verification and password recovery
  • Real-time: Supabase live subscriptions for instant message delivery
  • Anonymity Layer: Auto-generated aliases per group chat; real identity stored only server-side via user ID
